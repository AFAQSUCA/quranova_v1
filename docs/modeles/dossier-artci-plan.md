# Dossier type ARTCI — PLAN (livrable L-05)

> **Ce document n'est PAS un dossier prêt à déposer.** Il liste ce qu'un conseil juridique devra confirmer et rédiger. Cadre : loi n° 2013-450 du 19 juin 2013 relative à la protection des données à caractère personnel ; autorité : ARTCI (§16).
> **À faire avant la première mission payante** : formalités du prestataire (§16.5). Le dossier type facilite celles du **client**, responsable de traitement de ses concours.

## À qualifier avec le conseil juridique
1. Le régime applicable : **déclaration** ou **demande d'autorisation** (données **sensibles** : conviction religieuse déduite de la participation ; données de **mineurs**) ;
2. Les rôles : client **responsable de traitement**, prestataire **sous-traitant** pour les données du concours ; prestataire **responsable de traitement** pour ses données de gestion (clients, opérateurs, comptes, facturation) ;
3. Le **transfert hors de Côte d'Ivoire** : aucun en V1 (serveur de salle sans Internet) ; à instruire avant la V2 (instance centrale).

## Contenu du dossier (une fiche par traitement)
| Rubrique | Éléments à fournir (déjà disponibles dans QURANOVA) |
|---|---|
| Identité du responsable / du sous-traitant | à compléter |
| **Finalité** | organisation, conduite et publication des résultats d'un concours coranique |
| **Base légale** | consentement exprès et écrit (représentant légal pour les mineurs) ; règlement du concours |
| **Catégories de personnes** | candidats, représentants légaux, jurés |
| **Catégories de données** | identité, date de naissance, ville, structure, notes, classement ; **aucune** pièce d'identité, photographie ni donnée de santé (§16.1) |
| **Destinataires** | organisateur, jurés, prestataire |
| **Durées** | §16.3 (tableau) |
| **Mesures de sécurité** | comptes nominatifs, mot de passe ≥ 12 caractères, **deuxième facteur**, limitation des essais, cloisonnement par client, journal d'audit **chaîné** vérifiable, sauvegardes toutes les 15 min, serveur sans Internet, chiffrement des fichiers sensibles [à finaliser, D20] |
| **Droits des personnes** | procédure §16.4 (délai 15 jours, anonymisation après publication) |
| **Violation de données** | notification sans délai au client, puis à l'ARTCI selon les exigences |
| **Registre des traitements** | §16.6, mis à jour à chaque mission |
