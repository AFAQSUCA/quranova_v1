# 23. Livrables

Le prestataire étant son propre maître d'ouvrage, les livrables ci-dessous constituent le référentiel interne du projet ; ils conditionnent la capacité à former des opérateurs et à reprendre le code dans la durée.

| Réf. | Livrable | Contenu | Échéance |
|---|---|---|---|
| L-01 | Code source | Dépôt Git avec historique, étiquette par version, README, fichiers Docker, scripts d'installation du serveur de salle, liste et licences des dépendances. | Continu ; version V1 à la fin de la phase 2 |
| L-02 | Documentation technique | Installation et mise à jour du serveur de salle, sauvegarde et restauration, intégration du corpus, gestion des secrets. | Fin de la phase 3 |
| L-03 | Guide de l'opérateur | Procédure complète d'une mission (§22.1), listes de contrôle J-1 et jour J, procédures d'incident (§13.6). | Avant le concours pilote |
| L-04 | Fiches mémo | Fiche d'une page pour les jurés et fiche de conduite d'une prestation pour l'opérateur. | Avant le concours pilote |
| L-05 | Modèles destinés aux clients | Modèle d'import des candidats, formulaire de consentement parental, contrat de mission avec clause de protection des données, dossier type ARTCI. | Avant le concours pilote |
| L-06 | Tests | Tests automatisés (unitaires, intégration, bout en bout des écrans temps réel), script de simulation de charge, jeu de données fictives, cahier d'autorecette (REC). | Fin de la phase 3 |
| L-07 | Procès-verbal de validation du corpus | Empreintes, contrôles automatiques, validation signée du référent coranique. | Fin de la phase 0 |
| L-08 | Procès-verbal d'autorecette | Résultats des tests REC et de la répétition générale. | Fin de la phase 3 |
| L-09 | Bilan du concours pilote | Déroulement, incidents, mesures (§18.1), retours du client et des jurés, corrections décidées. | Fin de la phase 4 |
| L-10 | Supports commerciaux | Plaquette, grille tarifaire, vidéo et photos du concours pilote, références. | Phase 5 |
